# 0008. npm instead of pnpm

- Status: Accepted
- Date: 2026-10-28
- Evidence: owner's decision; lockfile comparison below

## Context

ADR 0001 chose pnpm 12 via corepack, as the plan says. On 2026-10-28 the owner decided to switch to
npm, which ships with Node. Besides installing packages, pnpm gave us three guarantees:

- dependency install scripts run only when allowed (`pnpm-workspace.yaml` allowed esbuild);
- versions published less than a day ago are not installed;
- a strict `node_modules`: code can import only the packages it declares.

A plain `npm install` resolves the `package.json` ranges afresh. On 2026-10-28 that changed 76
packages compared with `pnpm-lock.yaml`, including wxt 0.21.4 → 0.21.5 and a major bump of
`@1natsu/wait-element` (4 → 5).

## Decision

- **npm 11.19** (`packageManager: npm@11.19.1`, bundled with Node 24.22.1). `package-lock.json`
  replaces `pnpm-lock.yaml`; CI installs with `npm ci`.
- **Same versions as pnpm.** The first `package-lock.json` was generated from the last
  `pnpm-lock.yaml` (temporary exact pins and `overrides`, removed afterwards), so all 319 packages
  keep the versions the phase 0–2 checks ran on. Dependency upgrades are separate changes.
- **Install scripts:** `allowScripts` in `package.json` allows esbuild and denies fsevents (its
  script rebuilds a binary the package already ships; pnpm never ran it either). `.npmrc` sets
  `strict-allow-scripts=true`, so a dependency with an unreviewed install script fails the install.
  Review the script, then `npm approve-scripts <pkg> --no-allow-scripts-pin` or
  `npm deny-scripts <pkg>`.
- **Release age:** `.npmrc` sets `min-release-age=1` (days). As with pnpm, if a needed version is
  too new, pin a slightly older one instead of adding exclusions.

## Consequences

- Commands: `npm run <script>`, `npm test`, `npx <bin>`. Use `npm run -s` when redirecting a
  script's stdout, otherwise npm's banner lines end up in the file.
- The strict `node_modules` is gone: npm hoists transitive dependencies, so importing an undeclared
  package works until that dependency moves. Declare every package you import in `package.json`;
  add a lint rule for undeclared imports if this bites.
- The `.npmrc` policy was checked with npm 11.19.1; older npm versions may not enforce it.
- `docs/plan.md` still says pnpm; it is kept as written, this ADR supersedes it.
